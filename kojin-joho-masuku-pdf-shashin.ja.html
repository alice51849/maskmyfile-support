「電話番号は下 4 桁だけ残したい」「名前は仮名に置き換えて件数だけ共有したい」といった場合は、テキスト系ファイルの部分マスクや仮名化が使えます。

ぼかしや注釈の黒い四角では足りないことがある

  • ぼかし：太い数字は読み取れてしまうことがあります。そのため Mask My File は画像にぼかしを使わず、恒久的な塗りつぶしか削除だけを行います。
  • PDF の注釈の四角：上に重なっているだけで、下の文字を選択・検索できる場合があります。
  • メタデータ：作成者、端末、位置などがファイルに残ることがあります。形式が対応していれば削除できます。

送る前の 4 ステップ

  1. 相手に必要な情報を決める：大家さんに必要なのは氏名と日付で、口座番号は不要、など。
  2. 出てくる場所をすべて探す：同じ番号が 1 ページ目と 7 ページ目にあることも。テキストは一致箇所をまとめて検索できます。最大 100 ファイルの一括処理とファイル横断検索にも対応。
  3. マスクして新しいコピーを作る：元のファイルは上書きされません。
  4. 開き直して確認：Mask My File は新しいコピーを開き直して確認してから Private Ready を表示します。自分でも消した文字を検索してみると安心です。

すべて端末内で処理、アップロードなし

アカウント、広告、トラッキング、分析、コンテンツのアップロードは一切ありません。Apple Vision と組み込みの Tesseract OCR はローカルで動作し、顔検出は領域を作るだけで個人を特定しません。一時作業ファイルやプロジェクトは削除するまで端末内に残ります。

よくある質問

写真の個人情報はぼかしでマスクできますか？

Mask My File は画像にぼかしを使いません。恒久的な塗りつぶし（黒塗り）または削除のみで、顔とバーコードの検出は確認用の領域を示すだけです。

電話番号の一部だけ残すことはできますか？

テキスト、CSV、TSV、JSON、XML、HTML、RTF では、一致箇所にアスタリスクの部分マスクを使えます。全体マスク、プレースホルダー、仮名化、削除も選べます。

PDF の個人情報もマスクできますか？

できます。ページ単位で作業し、全幅プレビューと最大 5× ズームで範囲を手動で正確に選べます。

ファイルはサーバーにアップロードされますか？

いいえ。すべて端末内で処理され、アカウントもトラッキングもコンテンツのアップロードもありません。

元のファイルは変更されますか？

いいえ。元のファイルは上書きされず、開き直して確認した新しいコピーが作られます。

料金は月額ですか？

いいえ。一度の購入で出力ファイルの検証と一括処理を無制限に使える買い切りです。サブスクリプションはありません。
