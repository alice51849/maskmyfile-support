Mask My File으로 할 수 있는 것

  • 자동으로 찾는 정보：이름, 전화번호, 이메일, 주소, 계좌·결제 정보를 찾아내고, 선택한 부분만 영구적으로 가립니다.
  • 지원 파일：PDF, 사진, 스크린샷, 텍스트 파일. 텍스트, JSON, XML, HTML, CSV, TSV, RTF는 모든 일치 항목을 검색해 마스크·자리표시자·가명·제거를 적용합니다.
  • 원본 보호：원본은 절대 덮어쓰지 않고, 다시 열어 검증한 새 사본을 만듭니다.
  • 메타데이터：형식이 허용하면 메타데이터도 지웁니다.
  • 여러 파일：PDF는 페이지 단위로, 배치는 최대 100개 파일까지 개별 미리보기와 파일 간 검색을 지원합니다.

자주 묻는 질문

어떤 파일의 개인정보를 가릴 수 있나요?

PDF, 사진, 스크린샷, 텍스트 파일을 지원합니다. 텍스트 계열은 JSON, XML, HTML, CSV, TSV, RTF까지 다룹니다.

가린 부분이 나중에 다시 보이지는 않나요?

사진·PDF 같은 시각 파일은 영구적인 불투명 가리기 또는 제거만 지원합니다. 원본은 그대로 두고, 다시 열어 검증한 새 사본을 만듭니다.

얼굴이나 바코드도 자동으로 가려 주나요?

얼굴·바코드 감지는 검토용 영역만 표시합니다. 직접 확인한 뒤 가릴 부분을 고르면 됩니다. 얼굴 감지는 사람을 식별하거나 얼굴 데이터를 보관·공유하지 않습니다.

파일이 서버로 올라가나요?

아니요. 모든 처리는 기기에서 이루어지며 콘텐츠 업로드가 없습니다. 계정도 필요하지 않습니다.

파일이 많을 때도 쓸 수 있나요?

배치는 최대 100개 파일까지 파일별 미리보기, 파일 간 검색, 파일별 수동 선택을 지원합니다.
