Como tarjar PDF no iPhone antes de enviar?

Resposta curta: abra o PDF no Mask My File, deixe o app encontrar nomes, telefones, e-mails, endereços e dados de conta, escolha só o que quer ocultar e gere uma cópia nova com tarja sólida permanente. O app reabre e verifica a cópia, e o original nunca é sobrescrito.

Passo a passo

  1. Abra o PDF (ou foto, captura de tela ou arquivo de texto) no Mask My File.
  2. Revise o que foi encontrado: nomes, telefones, e-mails, endereços, dados de conta e de pagamento.
  3. Escolha só o que deve sumir e ajuste seleções manuais, página a página, com zoom de até 5×.
  4. Gere a cópia: tarja sólida permanente ou remoção, e metadados removidos quando o formato permite.

Quando usar

  • Ficha de aluguel e cópia de RG enviadas para imobiliária
  • Holerite pedido em financiamento ou cadastro
  • Arquivos de clientes compartilhados com terceiros

Por que não só um retângulo preto

Desenhar uma forma por cima em um editor comum pode deixar o conteúdo original no arquivo. O Mask My File aplica a tarja e entrega uma cópia nova, reaberta e verificada — e o original fica intacto para você.

Perguntas frequentes

O Mask My File sobrescreve o meu PDF original?

Não. O original nunca é sobrescrito: você recebe uma cópia nova, reaberta e verificada.

Consigo tarjar vários PDFs de uma vez?

Sim. É possível processar até 100 arquivos com pré-visualizações individuais, busca entre arquivos e seleções manuais para cada um.

Ele tarja fotos de documentos também?

Sim. Funciona com PDF, fotos, capturas de tela e arquivos de texto. A detecção de rostos e códigos de barras apenas marca áreas para você revisar.

Os meus documentos são enviados para algum servidor?

Não. Tudo é processado no seu dispositivo, sem conta, publicidade, rastreamento, análise ou envio de conteúdo. O OCR funciona localmente.

Ele remove metadados do PDF?

Sim, quando o formato permite.
