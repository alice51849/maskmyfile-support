How to redact a PDF on iPhone so the text is really gone

Before you send a rental application, a medical record or a pay stub, you hide the Social Security number and the account details. The common shortcut, drawing a black rectangle on top, can fail quietly: in many PDFs the box is only a layer on top, and the text underneath can still be selected, copied or found by search. The 30-second test for any redacted file

  1. Open the redacted copy, not the original.
  2. Use search to look for a word you hid, for example the last four digits of the number.
  3. Try to select and copy the area under the box, then paste it into a note.
  4. Check the file’s information: author names and other metadata can survive even when the page looks clean.

If search finds the word or the paste shows the text, the information was covered, not removed. Do not send that file.

The goal is to keep the useful context and permanently hide only the details the recipient does not need. Over-redacting is how a document gets sent back and the whole process starts again.
