Why fake redactions happen

Many PDF editors, annotation tools and phone markup tools add a black shape as a separate layer on top of the page. On screen and on paper it looks redacted. But the original text is still in the page content, so anyone can select it, copy it into a note, or find it with search. Exporting or “printing to PDF” does not always flatten the box into the page either.

How to really remove the text

  1. Start from the original, not the fake-redacted copy.
  2. Use a real redaction feature that deletes the content under the box and makes a new file, rather than a drawing or highlight tool.
  3. Remove metadata (author names, titles, edit history) where your tool supports it.
  4. Check the new copy here or by hand: search for a value you hid, and try selecting the area under each box.

Converting every page to an image also removes the text layer, but it makes the file larger and unsearchable, and the private details must still be covered in the image before you convert.

How this checker keeps your file private

  • Your PDF is read by your own browser and the text is extracted on this page, using the open-source pdf.js library from Mozilla.

  • The only network requests are for the page and the pdf.js library files themselves. You can disconnect from the internet after the page loads and the checker still works.

Frequently asked questions

Is my PDF uploaded anywhere?

No. The checker reads the file with your browser's own file reader and extracts the text on this page. It does not send the file or its text to any server and does not save it. The only thing downloaded is the open-source pdf.js library itself.

The checker found my hidden text. What now?

Do not send that file. The black box was only drawn on top. Go back to the original and redact it with a tool that removes the content from a new copy, then run the new copy through the checker again.

The checker found no text at all. Is my PDF safe?

Not necessarily. A scanned PDF or a PDF made from photos holds pictures of pages, not selectable text, so there is nothing to extract. Look at the pages themselves: the private details must be covered in the image, and metadata can still hold names.

Does it check metadata or hidden layers?

It shows the document's basic properties (such as title and author) when the PDF has them, and all selectable text on each page. It does not inspect attachments, form fields or older saved versions inside the file.
