How to mask personal data in a CSV, JSON or text file on iPhone

You need to send a customer export to a contractor, attach a log file to a support ticket, or share a spreadsheet of sign-ups with a coworker. The structure has to stay useful, but the names, emails, phone numbers and account details should not travel with it. Masking data means hiding the private values while keeping the file readable. Here is how to decide what to mask, which masking style fits, and how to do it on an iPhone without uploading the file anywhere.

Five ways to mask a value

StyleWhat happens to the valueGood for
Full maskThe whole value is hiddenAccount and payment details nobody downstream needs
Partial maskPart of the value is hidden, part stays visibleLetting someone match a record without seeing the full number
PlaceholderThe value is swapped for a neutral labelSample data, screenshots for a bug report, documentation
PseudonymThe value is replaced with a substituteKeeping rows distinguishable while hiding who they belong to
RemovalThe value is deletedFields the recipient should never see at all

The right choice depends on what the recipient has to do with the file. If they only need totals, remove or fully mask. If they need to tell rows apart, a pseudonym or a partial mask keeps the file workable.

What to mask in common exports

  • Customer or sign-up list (CSV, TSV): names, emails, phone numbers and street addresses. Keep dates, plan names and counts.
  • App or server log (text, JSON): emails, phone numbers and account identifiers that appear inside messages. Keep timestamps and error text.
  • API response or config sample (JSON, XML): personal fields and payment details. Keep the keys and structure so the sample still makes sense.
  • Exported web page or rich text (HTML, RTF): contact details in signatures and footers.

Check the copy before you send it

  1. Open the new copy, not the original.
  2. Search it for one value you masked, such as an email domain or the last digits of a number.
  3. Look at a few rows to confirm the file still has the columns and structure the recipient needs.

Frequently asked questions

What is the difference between a partial mask, a placeholder and a pseudonym?

A partial mask hides part of a value and keeps the rest visible, a placeholder swaps the value for a neutral label, and a pseudonym replaces it with a substitute value. You can also mask the whole value or remove it.

Which file types can Mask My File search and mask?

Text, JSON, XML, HTML, CSV, TSV and RTF files. For PDFs, photos and screenshots it applies permanent solid redaction or removal instead.

Does it upload my data export?

No. Everything is processed on your device, with no account, advertising, tracking, analytics or content upload.

Is my original file changed?

No. Originals are never overwritten; you get a new copy that is reopened and verified.

Can I mask several exports at once?

Yes. You can protect up to 100 files at once with individual previews, cross-file search and per-file manual selections. Batch processing is part of the one-time purchase.
